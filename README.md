# Grama Khata Micro Finance

## Project Overview
Grama Khata Micro Finance is an Android application developed to support rural financial management and micro-finance services. The application helps users manage financial records, transactions, and loan-related activities digitally.

## Features
- User Authentication
- Loan Management
- Financial Record Tracking
- Transaction History
- Firebase Integration
- Real-time Database Support

## Technologies Used
- Kotlin
- Android Studio
- Firebase Authentication
- Firebase Realtime Database
- MVVM Architecture
